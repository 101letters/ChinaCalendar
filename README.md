# 中国节假日补充

补充苹果日历「中国节假日」之外的内容，一个订阅全部包含。

[![](https://img.shields.io/github/stars/101letters/ChinaCalendar)](https://github.com/101letters/ChinaCalendar/stargazers)
[![](https://img.shields.io/github/license/101letters/ChinaCalendar)](https://github.com/101letters/ChinaCalendar/blob/master/LICENSE)

## 包含内容

- 农历每日日期
- 二十四节气
- 中国传统节日与纪念日
- 西方节日（情人节、愚人节、复活节、母亲节、父亲节、万圣节、感恩节、平安夜、圣诞节）

> 已移除：三伏、数九、法定节假日调休补班（苹果日历已自带）。

## 订阅链接

复制下面链接，粘贴到日历订阅地址：

```
https://101letters.github.io/ChinaCalendar/china-holidays-extra.ics
```

## 订阅方式

- **iPhone**：日历 → 日历 → 添加日历 → 添加订阅日历
- **Mac**：日历 → 文件 → 新建日历订阅
- **安卓**：设置 → 日历 → 添加日历 → URL 导入

仓库地址：[https://github.com/101letters/ChinaCalendar](https://github.com/101letters/ChinaCalendar)
