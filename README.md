## 订阅方式

> 复制完整链接至下述目标区域粘贴订阅

#### 苹果设备订阅

- iPhone 订阅(iOS15 以上) **[日历-日历-添加日历-添加订阅日历]**
- Mac 订阅 **[日历-文件-新建日历订阅]**

#### 安卓设备订阅

- 通用订阅方式 **[设置-日历-添加日历-URL 导入]**
