中国节假日补充

补充苹果日历「中国节假日」之外的内容，一次订阅全部包含。

包含内容

  • 农历每日日期（腊月初二、正月初一…）
  • 二十四节气（立春、雨水…冬至大寒）
  • 中国传统节日与纪念日（小年、重阳、清明等）
  • 西方节日（情人节、愚人节、复活节、母亲节、父亲节、万圣节、感恩节、平安夜、圣诞节）

已移除：三伏、数九、法定节假日调休补班（苹果日历已自带）。

订阅链接

复制下面链接，粘贴到日历订阅地址即可：

https://101letters.github.io/ChinaCalendar/china-holidays-extra.ics

订阅方式

苹果设备

  • iPhone：日历 → 日历 → 添加日历 → 添加订阅日历
  • Mac：日历 → 文件 → 新建日历订阅

安卓设备

  • 设置 → 日历 → 添加日历 → URL 导入

本日历不会获取任何用户信息。

仓库地址：https://github.com/101letters/ChinaCalendar
